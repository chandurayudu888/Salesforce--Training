1. What is Flow Builder?
    Flow Builder is a Salesforce automation tool used to automate business processes without writing much code. It allows users to create workflows using drag-and-drop elements. With Flow Builder, organizations can automate tasks like sending emails, updating records, approvals, notifications, and data collection. It helps reduce manual work and improves efficiency.

2. Types of Flows
Screen Flow
A Screen Flow is an interactive flow that collects information from users through screens.
Example:
* Student admission form
* Employee registration form

Record-Triggered Flow
A Record-Triggered Flow runs automatically when a record is created, updated, or deleted.
Example:
* Send email when admission status becomes “Approved”
* Automatically update student status after fee payment

6. Reflection: Why Automation Matters in Enterprise Systems
Automation is important in enterprise systems because it saves time, reduces manual effort, and improves accuracy. Organizations handle thousands of records and repetitive tasks every day, which can lead to delays and human errors if managed manually. Automation helps businesses complete tasks faster, maintain consistent processes, improve productivity, and provide better customer or student experiences. It also allows employees to focus on more important work instead of repeating routine tasks.
